
# AUCare – Campus Maintenance and Complaint Management System

AUCare is a full-stack web application designed to simplify campus maintenance by allowing students to submit complaints and administrators to manage and update their status.

## Features
- Student registration and login
- Submit maintenance complaints
- Track complaint status
- Admin login and complaint management
- Role-based access control

## Technology Stack
- Frontend: React, Vite, CSS
- Backend: Java, Spring Boot
- Database: MySQL
- API Testing: Postman

## Project Structure
- `frontend/` – React frontend
- `campus-maintenance/` – Spring Boot backend

## Local Setup
1. Install Java, Node.js, and MySQL.
2. Configure database credentials locally in `application.properties`.
3. Start the Spring Boot backend.
4. Run `npm install` and `npm run dev` inside the `frontend` directory.

## Security
Database credentials and other secrets should not be committed to version control.
